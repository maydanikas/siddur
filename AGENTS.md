# Instructions for AI agents

Перед **любой** задачей в этом репозитории:

1. **[PROJECT.md](./PROJECT.md)** — база знаний (стек, ветки, TTS, данные молитв).
2. **[AGENT_TASKS.md](./AGENT_TASKS.md)** — стек задач, активная работа, журнал выполненного.

**Основная ветка:** `version-2.0` (production + новые задачи). Beta: `version-2.1`.

Правило Cursor: `.cursor/rules/agent-workflow.mdc` (always apply).

После задачи — записать результат в `AGENT_TASKS.md` и при необходимости обновить `PROJECT.md`.
